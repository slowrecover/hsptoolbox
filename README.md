# HSP Toolbox

Free, local-first browser tools for highly sensitive people, overthinkers, and anyone who gets stuck in self-criticism, overwhelm, decision fatigue, or task initiation.

**Live demo:** https://slowrecover.github.io/hsptoolbox/

## Why this project exists

I started building these tools for problems I know personally: having too many thoughts at once, making a task feel too big to start, being harsh with myself, getting stuck in repeated decisions, and needing a small way to move forward.

I have built **10 free browser tools** around these everyday problems. HSP Toolbox is the main open-source home where I am gradually consolidating and improving them.

The goal is deliberately simple: small tools that help in the moment, without turning a difficult moment into another account, subscription, or complicated system.

## Principles

- **Free to use** — no paywall.
- **Local-first** — user input is designed to stay on the user's device.
- **No login required** — open the tool and use it.
- **No tracking of personal entries** — the tools are designed around privacy rather than data collection.
- **Small and practical** — each tool should solve one narrow problem clearly.
- **No forced positivity** — the tools aim to make thoughts and actions easier to examine, not to tell users how they should feel.

## Tools in this repository

The collection is still being consolidated. Current tools and experiments include:

- **砍小器 / Task Shrinker** — turns an overwhelming task into a step small enough to start.
- **Inner Talk Translator** — separates harsh self-talk into feelings, facts, and interpretations.
- **闭眼冲 / Decision Once** — reduces the cost of repeatedly deciding whether to do the same task.
- **情绪记录本 / Emotion Notebook** — helps capture a trigger, feeling, and one small next step.
- **想法停机坪 / Idea Runway** — parks new ideas so they do not interrupt the thing already in progress.
- **Dare to Cringe** — helps make room for embarrassment when it is blocking an important action.
- **Inner Voice** — a privacy-first tool for examining negative self-talk.

More of the 10 tools are being cleaned up and brought into this repository over time.

## Run locally

Most tools are plain HTML/CSS/JavaScript and do not require a build step.

```bash
git clone https://github.com/slowrecover/hsptoolbox.git
cd hsptoolbox
```

Then open `index.html` in a browser, or serve the folder with any simple local web server.

- documentation improvements

## Privacy

The project is intentionally designed around local use. Please do not add analytics, trackers, authentication requirements, or remote storage of user entries without first opening an issue and discussing the change.

## Project status

HSP Toolbox is early and actively maintained. It does **not** yet have a large GitHub community or star count. I am sharing the tools with real users outside GitHub, learning from their feedback, and using that feedback to decide what to improve next.
