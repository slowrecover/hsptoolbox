# 情绪记录本手动测试

上线前请在安卓 Chrome 中完成以下检查：

1. 从工具箱首页进入“情绪记录本”，确认记录、时间线和回看正常显示。
2. 输入一段文字但不点击“记下来”，关闭页面后重新打开，确认草稿恢复。
3. 保存一条记录，刷新并重新打开，确认记录仍存在。
4. 导出备份，确认下载到 JSON 文件。
5. 再导入该备份，确认不会生成重复记录。
6. 在浏览器菜单选择“安装应用”或“添加到主屏幕”，确认桌面图标名称为“情绪记录”。
7. 安装后从桌面启动，确认直接进入情绪记录本。
8. 断网后重新打开已安装应用，确认页面和已有记录仍可查看。

> 数据只保存在当前浏览器/安装应用的本地存储中。清除站点数据仍会删除记录，因此应定期导出备份。
