# Contributing to HSP Toolbox

Thanks for helping improve HSP Toolbox.

The project is intentionally small, privacy-first, and easy to use. Contributions should preserve those qualities.

## Good contributions

- fix bugs
- improve accessibility
- simplify interactions
- improve wording or translations
- add tests
- improve documentation
- identify privacy or data-handling risks

## Before adding a new feature

Please open an issue first if a change would:

- send user-entered content to a server
- add analytics or tracking
- require login or an account
- introduce a paid dependency for end users
- substantially change the purpose of an existing tool

## Pull requests

Keep pull requests focused on one change when possible. Please explain:

1. what changed
2. why it helps
3. how you tested it
4. whether it changes privacy or data handling

## Local development

Most tools are plain HTML/CSS/JavaScript. Clone the repository and open the relevant HTML file in a browser, or serve the repository with a simple local web server.

## Design principles

When in doubt, prefer:

- fewer steps
- clearer language
- local processing
- no account requirement
- no tracking
- one small problem per tool

Thanks for contributing.
