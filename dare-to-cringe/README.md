# Dare to Cringe

**Your life matters more than looking cool.**

Dare to Cringe is a free, mobile-first courage tool for the real thing someone keeps avoiding because they might look awkward. It turns fear into one small action, then compares the predicted embarrassment with what actually happened.

Entries stay in the user's browser. There is no account, backend, upload, analytics, or external API.

Live site: https://slowrecover.github.io/hsptoolbox/dare-to-cringe/

Challenges should stay safe, legal, consensual, and low-stakes. This is not therapy or medical care.
